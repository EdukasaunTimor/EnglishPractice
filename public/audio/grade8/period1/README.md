# Grade 8 - Period 1 Audio Files (1.x.x)

Place all Grade 8 Period 1 audio files in this directory.
Naming convention: `1.x.x [Title].mp3` or `.wav`

Examples:
- `1.1.1 Dialogue - Greetings and Introductions.mp3`
- `1.1.2 Listening Practice - Meeting New Friends.mp3`
- `1.2.1 Pronunciation - Vowel Sounds.mp3`
